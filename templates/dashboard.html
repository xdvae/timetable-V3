Getting started

  1. Set up Config — working days, class periods, the lunch break, and class-size limits.
  2. Add Rooms — theory rooms and labs, with their capacity.
  3. Add Faculty and, if needed, mark when they're unavailable.
  4. Add Programs (e.g. BCA, B.Tech CSE).
  5. Add Enrollments — program, year, and student count. Sections and lab groups are created automatically.
  6. Add Subjects for each enrollment.
  7. Add Teaching Assignments — who teaches what, to which section or lab group.
  8. Open Timetable and generate it.
